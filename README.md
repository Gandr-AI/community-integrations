# Gandr community integrations

Guides for wiring Gandr into third-party stacks, written by the community, reviewed before merge.

**Pricing:** unlimited, unmetered stream plans from **$150/mo** (annual), or **$10 a month for one million tokens** (one token is one character), [gandr.ai/pricing](https://gandr.ai/pricing).

## Submit a guide

1. Fork this repo and add a folder: `your-integration/README.md` plus any code.
2. Show the smallest working path: install, configure, first audio.
3. No keys in the repo, ever. Readers bring their own.
4. Open a PR. We test every guide against the live API before merging.

## What makes a good guide

- One stack per guide (a framework, a telephony provider, an automation tool)
- The first audio byte arrives in under five minutes of following it
- Honest notes about what didn't fit, those save the next reader an hour
